### 3.3 GA4 — cassé, mais pas pour la raison qu'on croit (P0-SEO-1)
- Propriété correcte : `553599961` / `G-PTVRXLF7NR` / jobxpress.fr ✅
- Balise gtag déployée ✅ (préload visible dans le HTML live)
- **Mais : 0 rows sur 90 jours.**
- **Root cause** : la CSP servie par Caddy sur `jobxpress.fr` :
  ```
  script-src 'self' 'unsafe-inline' https://*.jobxpress.fr
  connect-src 'self' https://api.jobxpress.fr
  ```
  bloque `www.googletagmanager.com` (script) **et** `www.google-analytics.com` (collecte).
  La balise GA4 est morte-née depuis l'installation (10/09). Ironie : la CSP (durcissement sécurité
  de la bascule VPS du 04/09) est arrivée avant la balise (10/09) et l'a neutralisée.
- Conséquence : **aucune donnée de trafic, aucune conversion mesurée, A/B testing (Phase 5) aveugle.**
- Fix (Caddyfile, bloc jobxpress.fr) :
  ```
  script-src 'self' 'unsafe-inline' https://www.googletagmanager.com https://*.jobxpress.fr;
  connect-src 'self' https://api.jobxpress.fr https://*.google-analytics.com https://*.analytics.google.com https://www.googletagmanager.com;
  img-src 'self' data: https://www.google-analytics.com https://www.google.fr https://www.google.com;
  ```
